# 数据处理与隐私声明

TiebaPure-Mac 专注于提供纯净的原生 macOS 贴吧浏览体验，严格遵循本地优先与最小数据收集原则。

## 网络通信边界

- **直连官方服务器**：所有网络请求均直接与百度贴吧官方服务端接口进行 HTTPS 加密通信。应用不设任何自建中转代理服务器、遥测收集服务器或第三方统计上报服务。
- **免登录浏览**：在未登录状态下，应用仅调用公开只读接口读取公开推荐、进吧列表及帖子内容。

## 账号与凭据管理

- **官方 WebKit 隔离登录**：登录流程使用系统原生 WebKit 视图加载百度官方登录页面，应用不拦截、不注入也无法获取用户的明文登录密码。
- **Keychain 安全存储**：登录成功后提取的必要会话凭据直接写入系统 Keychain，使用专属标识符建立访问隔离。注销登录时，所有凭据即刻从 Keychain 中擦除。

## 本地数据存储

- **本地偏好与状态**：用户的外观模式、字体缩放、阅读设置保存在标准 UserDefaults 中。
- **浏览历史与缓存**：最近访问的贴吧、搜索历史与本地收藏数据均以加密或保护形式持久化在用户的 Application Support 目录下，不向任何第三方服务同步。
- **自动更新安全**：应用内软件更新通过 Sparkle 框架拉取 GitHub Releases 的签名源文件。更新包下载与校验完全基于 Ed25519 签名与 SHA256 哈希比对，无其他中间数据上报。
