# 数据处理与隐私声明

TiebaPure-Mac 专注于提供纯净的原生 macOS 贴吧浏览体验，严格遵循本地优先与最小数据收集原则。

## 网络通信边界

- **直连服务端**：贴吧请求通过 HTTPS 直连百度服务，配置了自动更新的构建还会连接 GitHub Releases。应用没有自建代理或统计上报服务。
- **免登录浏览**：在未登录状态下，应用仅调用公开只读接口读取公开推荐、进吧列表及帖子内容。

## 账号与凭据管理

- **官方 WebKit 隔离登录**：登录流程使用系统原生 WebKit 视图加载百度官方登录页面，应用不拦截、不注入也无法获取用户的明文登录密码。
- **Keychain 安全存储**：登录成功后提取的必要会话凭据直接写入系统 Keychain，使用专属标识符建立访问隔离。注销登录时，所有凭据即刻从 Keychain 中擦除。

## 本地数据存储

- **本地偏好与状态**：用户的外观模式、吧内主题排序偏好、屏蔽名单以及发帖与签到设置保存在标准 UserDefaults 中。
- **本地历史记录**：最近访问的贴吧、搜索历史、浏览历史、阅读位置与内容草稿存放在用户资源库的 `Application Support/TiebaPure-Mac/Persistence/v1` 下，目录权限限于当前系统用户。
- **关注与收藏**：关注贴吧和收藏帖子属于登录账号，客户端将这些操作提交到百度服务器，并回读结果。
- **自动更新**：配置了签名更新源的构建由 Sparkle 从 GitHub Releases 读取更新信息，并使用 Ed25519 签名验证更新源和更新包。
